# Design Context

This is **Pedro Garcia's portfolio** — a **brand** surface (the design *is* the product),
targeting a primarily **technical** audience (eng leads, CTOs) to win both full-time roles
and freelance work. Personality: **sharp · precise · technical**.

See `PRODUCT.md` for the full strategic brief (users, purpose, anti-references, design
principles, accessibility) and `DESIGN.md` for the visual system (palette, typography,
components). Read both before changing any UI. Core guardrails: no generic-AI / template
look, no corporate-SaaS sterility, no flashy overdesign, no clutter — and **show, don't
tell**: prove capability through the work, never assert it.
